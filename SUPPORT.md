# Support

Thank you for using Sage.is projects! We're here to help.

## Getting Help

If you need help with any of our projects, here are some ways to get support:

### Documentation

- Check the project's README.md file for basic usage and setup instructions
- Review the CONTRIBUTING.md file for development guidelines
- Visit [https://sage.is](https://sage.is) for more information

### Issues

If you've found a bug or have a feature request:

1. Check if the issue already exists in the project's issue tracker
2. If not, create a new issue with a clear title and description
3. Include steps to reproduce (for bugs) or use cases (for features)
4. Add relevant labels if possible

### Security Issues

**Do not create public issues for security vulnerabilities.**

Please review our [Security Policy](SECURITY.md) for instructions on how to report security issues responsibly.

### Community

- Follow us on social media for updates and announcements
- Join discussions in GitHub Discussions (if enabled for the project)

### Commercial Support

For commercial support inquiries, please contact us through [https://sage.is](https://sage.is).

## Response Times

We do our best to respond to issues and questions in a timely manner. Please note:

- This is an open-source project maintained by volunteers
- Response times may vary depending on the complexity of the issue
- Security issues are prioritized and addressed as quickly as possible

## What to Expect

When asking for support:

- Be respectful and patient
- Provide as much relevant information as possible
- Follow up if you need clarification
- Close your issue when it's resolved

Thank you for being part of our community!
